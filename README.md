# 🚲 Rueda Libre - Alquiler de Bicicletas en Medellín

Sitio web informativo y de reservas para **Rueda Libre**, una empresa paisa dedicada al alquiler de bicicletas, recorridos guiados y mantenimiento básico en la ciudad de Medellín.

## 📋 Características

- **Inicio (`index.html`):** Presentación de la marca, servicios principales, catálogo de flota (7 tipos de bicicletas), rutas destacadas, pasos para alquilar y mapa de ubicación.
- **Tarifas y Rutas (`paginas/tarifas.html`):** Tablas de precios por hora, medio día y día completo, además de tarifas y detalles de recorridos guiados.
- **Reservas (`paginas/reservas.html`):** Formulario interactivo con validaciones nativas en HTML5 (documento, celular colombiano, fechas y aceptación de políticas).
- **Contacto directo:** Botón flotante de WhatsApp y correo electrónico en el pie de página.

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura semántica y validaciones de formulario.
- **Bootstrap 5.3 (CDN):** Diseño responsivo, sistema de grillas, tablas, tarjetas y componentes de navegación sin CSS personalizado.
